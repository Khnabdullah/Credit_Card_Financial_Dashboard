This Power BI project provides an interactive analysis of credit card customer and transaction data.

📊 Dashboards Included
Credit Card Customer Report – Analyzes revenue, income, interest, customers, age groups, jobs, education, marital status, and states.
Credit Card Transaction Report – Analyzes revenue, transaction amount, transaction count, interest, card categories, expenses, education, customer jobs, and transaction methods.
🛠️ Tools Used
Power BI
SQL
DAX
Data Visualization

The dashboard includes interactive filters for quarter, gender, income group, card category, and date, making it easy to explore credit card performance and customer behavior.
